# KT-Fahrzeugteile – Website (Entwurf)

Statische One-Page-Website für **KT-Fahrzeugteile**, Corneliusstr. 129, 40215 Düsseldorf.

- `index.html` – Seite (Hero mit animiertem Auto + Xenon-Scheinwerfern, Teilefinder, Kategorien, Angebot des Tages, Aktionen, Service, Marken, Kontakt)
- `css/style.css` – Design (Schwarz/Weiß + Rot)
- `js/main.js` – Xenon-Licht an/aus, Countdown, Teilefinder → WhatsApp, mobiles Menü
- `assets/` – Logo (Canva-Export + SVG-Bildmarke)

Lokal ansehen: `index.html` im Browser öffnen.
